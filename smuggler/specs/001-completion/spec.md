# Completion requirements
Preserve the playable logistics tycoon. Support all ten base locales with complete
translations and format-token parity, readable CJK/Cyrillic text and persistent
language selection. Present touch controls at least 88 logical pixels high (44
points on a 360-point-wide viewport). The introduction needs a visible step count,
large advance action and company setup; the contextual tutorial must teach actual
contract acceptance, dispatch and upgrades. Save corruption recovery must preserve
valid backups. QA must never overwrite the player's save. Blender output must
import successfully. Record mobile release prerequisites separately.
Acceptance: game tests pass, all language resources load, mobile panel screenshots
contain no clipped actions, and save/error cases have regression coverage.
