## Playback (code)

- `Scripts/Game/SoundCues.cs` (engine-free, tested): cue table (bus, dB, minimum gap, priority), sim event → cue, action
  result → cue (`ui_error` on a refusal, `coin` on Collect), music choice (`music_rush` while a storm / heatwave / cold snap
  runs or the needle is in the red band of a live shift, else `music_calm`).
- `Scripts/UI/VoltAudio.cs` (Unity): three code buses instead of an AudioMixer asset (a `.mixer` cannot be authored without
  the editor) — **sfx** (Settings → Effects, default **on**), **music** + **ambience** (Settings → Music, default **OFF**,
  P4 brief). One-shot pool with voice stealing by priority; music cross-fade 1 s; paused when the app loses focus; silent in
  batch mode (tests / CI).
- **Low-tier limits** (`SoundCues.Limits`): Low = 3 SFX voices and **no ambience bed**; Medium = 6 voices + ambience;
  High = 8. Music is streamed from disk, never fully in memory.
- Import settings: `Editor/VoltCity/VoltAudioImport.cs` (AssetPostprocessor): music Streaming + Vorbis 0.5, ambience
  CompressedInMemory, SFX DecompressOnLoad + forced mono. UNCOMPILED until the editor is installed.
- Hooks: every kit button → `ui_tap` (`UiKit.TapSound`); sim events → `SoundCues.ForSim`; purchases → `purchase`.
- Test: `P4Tests.Audio_EveryCueHasAFileAndALicence_MusicOffByDefault_LowLimits` (every cue has a file **and a row in this
  table**, no unused file, music off by default, Low limits, total size < 2.5 MB).
