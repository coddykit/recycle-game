# Architecture
Extend SaveManager with validated snapshot/restore and atomic write helpers, v1->v2 migration and future-version protection. GameManager owns the offline receipt and time watermark in that same save. Add DailyManager as an autoload with UTC task state in the same save; transactional claims snapshot/rollback through SaveManager. Extend existing tutorial manager for NextAction and existing HUD modal queue for suppression/back. Extend UIKit/audio/UIManager for motion and semantic feedback. Add dedicated regressions and pacing/scene QA using current simulation/model library; retain QA isolation.
